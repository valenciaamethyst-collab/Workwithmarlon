# Work with Marlon

Personal portfolio for Marlon Valencia, General Virtual Assistant.

Live website: https://workwithmarlon.online/

## Editing

- Edit content and contact details in index.html.
- Adjust the custom appearance in assets/css/portfolio.css.
- The original Dimension stylesheet is assets/css/main.css.
- Navigation and the email-draft helper are in assets/js/main.js. The contact email also appears here.
- Keep images/bg.jpg and images/overlay.png; the base stylesheet uses them.

The work examples are illustrative demos with fictional content, not client projects or claimed results. The contact helper opens a mailto draft in the visitor's own email app. It does not send or store messages. No backend, analytics, or tracking scripts are included.

## Deployment

The existing .github/workflows/static.yml publishes the repository through GitHub Actions on pushes to main. Manage the custom domain and HTTPS in the repository's Pages settings.
